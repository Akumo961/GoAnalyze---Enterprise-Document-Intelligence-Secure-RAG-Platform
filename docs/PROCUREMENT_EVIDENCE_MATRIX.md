# Procurement Evidence Matrix

This matrix prevents commercial claims from being confused with implementation evidence.

| Buyer concern | Evidence currently available | Evidence still required |
|---|---|---|
| Secure document intelligence | Repository implementation + Phase 14 demo | Production security assessment and target-environment validation |
| Grounded AI | Grounded RAG implementation + synthetic acceptance | Real corpus evaluation, citation accuracy benchmark, red-team assessment |
| Environmental workflows | Environmental review/workflow components + synthetic demo | Customer-approved workflow validation and domain acceptance |
| Regulatory knowledge | Extensible model and demo-only rules | Authoritative source onboarding, governance and legal/domain review |
| Auditability | Hash-chained audit implementation + demo | Production operational controls, retention, export and independent review |
| Tenant isolation | Authorization architecture | Adversarial cross-tenant test evidence in production-like deployment |
| Reliability | Automated tests where present | HA, failure-injection, recovery and operational history |
| Performance | Telemetry instrumentation | Workload benchmark on representative customer data |
| Business value | Measurement instrumentation | Baseline/pilot/post-pilot results |
| Deployment flexibility | Container/Kubernetes/Helm/Terraform architecture | Validation on each selected government environment |
| Supportability | Product/service model | Named support organization, runbooks, escalation and contractual SLA |
| Procurement eligibility | Not established by software repository | Supplier/legal/financial/procurement qualification |
| Government references | None claimed | Real references after successful deployments |
| Certifications/accreditations | None claimed | Independent assessments/certifications where required |

## Rule

A proposal, bid response, or sales presentation must distinguish **implemented**, **validated**, **planned**, and **customer-dependent** capabilities. Repository presence alone is not sufficient evidence of production fitness.
